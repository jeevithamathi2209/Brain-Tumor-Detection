# 🧠 Brain Tumor Detection System Using Deep Learning

A complete web application for detecting brain tumors from MRI scans using a Convolutional Neural Network (CNN). Built with Python Flask, TensorFlow/Keras, OpenCV, and pure HTML/CSS/JavaScript — no CSS frameworks.

---

## 📸 Project Features

| Feature | Details |
|---|---|
| 🤖 CNN Model | Custom-built 4-block Conv2D architecture |
| 🔍 4 Classes | Glioma, Meningioma, Pituitary, No Tumor |
| 📊 Dashboard | Stats, recent predictions, quick actions |
| 📄 PDF Reports | Auto-generated with ReportLab |
| 📋 History | Search, filter, delete predictions |
| 🔒 Auth | Registration, login, bcrypt password hashing |
| 💾 Storage | Excel files (.xlsx) — no database needed |
| 📱 Responsive | Mobile-friendly custom CSS |

## ⚙️ Installation Steps

### Step 1 — Prerequisites

- Python 3.9 or 3.10 (recommended)
- pip (Python package manager)
- VS Code (recommended IDE)
- Windows 10/11

### Step 2 — Clone / Download Project

```bash
# If using Git
git clone <repo-url>
cd BrainTumorDetection

# Or extract the ZIP and open in VS Code
```

### Step 3 — Create Virtual Environment

```bash
# In VS Code terminal (Ctrl+`)
python -m venv venv

# Activate on Windows
venv\Scripts\activate

# Activate on macOS/Linux
source venv/bin/activate
```

### Step 4 — Install Dependencies

```bash
pip install -r requirements.txt
```

> ⚠️ If TensorFlow installation fails, try:
> ```bash
> pip install tensorflow-cpu==2.13.0
> ```

## 📂 Dataset Setup

### Option 1 — Kaggle Dataset (Recommended)

1. Download from: https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset
2. Extract the ZIP
3. Place the **Training** and **Testing** folders inside `dataset/`:

```
dataset/
├── Training/
│   ├── glioma/        ← Training glioma images
│   ├── meningioma/    ← Training meningioma images
│   ├── notumor/       ← Training healthy images
│   └── pituitary/     ← Training pituitary images
└── Testing/
    ├── glioma/        ← Test glioma images
    ├── meningioma/    ← Test meningioma images
    ├── notumor/       ← Test healthy images
    └── pituitary/     ← Test pituitary images
```

> ✅ `train.py` **auto-detects** the structure. It also supports a flat layout
> (`dataset/glioma/` etc.) if you prefer to merge everything together.

### Minimum Dataset Size (for training)

| Class | Training | Testing |
|---|---|---|
| Glioma | 800+ | 100+ |
| Meningioma | 800+ | 100+ |
| Pituitary | 800+ | 100+ |
| No Tumor | 800+ | 100+ |

## 🚀 Model Training Steps

```bash
# Make sure virtual environment is activated
# Make sure dataset/ folders are populated

python train.py
```

Training will:
- Load and preprocess all images
- Split into Train / Val / Test sets (70/15/15)
- Train CNN with data augmentation
- Save best model to `models/brain_tumor_model.h5`
- Generate `models/confusion_matrix.png` and `models/training_curves.png`
- Print classification report

> Training time: ~20–60 min depending on dataset size and hardware.
> GPU (CUDA) will significantly speed up training.

## 🧪 Testing Procedure

### 1. Register & Login
- Go to http://localhost:5000/register
- Create an account
- Log in

### 2. Test Upload & Prediction
- Go to Upload MRI
- Upload any brain MRI image (.jpg/.png)
- Wait for analysis
- View result page

### 3. Test PDF Report
- From result page, click "Download PDF Report"
- PDF should download with all prediction details

### 4. Test History
- Go to History
- Use search box to filter by tumor type
- Try the filter buttons (All / Tumor / No Tumor)
- Test delete button

### 5. Test Profile
- Go to Profile
- Update name/email and save
- Change password

### 6. Test Sample MRI Images
- Download sample brain MRI images from the internet
- Or use images from the Kaggle dataset test set
- Upload each class to verify model accuracy

## 🔧 Troubleshooting

| Issue | Solution |
|---|---|
| `ModuleNotFoundError: tensorflow` | `pip install tensorflow==2.13.0` |
| `FileNotFoundError: brain_tumor_model.h5` | Run `python train.py` first |
| `openpyxl not found` | `pip install openpyxl` |
| Flask port in use | Change port: `app.run(port=5001)` |
| Images not showing | Check `static/uploads/` folder exists |
| PDF download fails | Check `static/reports/` folder exists |
