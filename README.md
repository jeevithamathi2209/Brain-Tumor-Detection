# 🧠 Brain Tumor Detection System

A deep learning-based web application for classifying brain MRI scans into four categories: **Glioma, Meningioma, Pituitary, and No Tumor**.

## 🚀 Features

- CNN-based MRI image classification
- Image preprocessing using OpenCV
- Flask web application
- User authentication with bcrypt
- Prediction history and dashboard
- Automated PDF report generation
- Model evaluation with confusion matrix and training curves
- Excel-based data storage

## 🛠️ Tech Stack

**Python | Flask | TensorFlow | Keras | OpenCV | NumPy | Pandas | Scikit-learn | ReportLab | HTML | CSS | JavaScript**
