Learn about the technology and vision behind BrainScanAI

The Project

Brain Tumor Detection Using Deep Learning

This system leverages Convolutional Neural Networks (CNN) trained on thousands of brain MRI scans to classify tumors into four categories with high accuracy. It provides a user-friendly web interface for medical imaging analysis.

Built as an end-to-end solution — from image preprocessing and deep learning inference to PDF report generation — this project demonstrates the practical application of AI in medical imaging.

🛠 Tech Stack

Python Flask TensorFlow Keras OpenCV NumPy Pandas HTML5 CSS3 JavaScript ReportLab bcrypt

🎯 Project Objectives

01

Accurate Classification

Classify brain MRI scans into Glioma, Meningioma, Pituitary tumor, or No Tumor using a deep CNN model.

02

Accessible Interface

Provide a clean, responsive web interface accessible from any device with no technical knowledge required.

03

Report Generation

Automatically generate professional PDF reports containing scan results, confidence scores, and patient info.

04

Historical Tracking

Maintain a searchable, filterable history of all predictions for each user with full data management.

05

Secure & Private

Protect user data with bcrypt password hashing, session management, and secure file storage.

06

Educational Impact

Demonstrate practical ML application for medical imaging to educate students and researchers.

🤖 CNN Model Architecture

📥 Input Layer (150×150×3)
↓
⬛ Conv Block 1 — Conv2D(32) + BatchNorm + MaxPool + Dropout
↓
⬛ Conv Block 2 — Conv2D(64) + BatchNorm + MaxPool + Dropout
↓
⬛ Conv Block 3 — Conv2D(128) + BatchNorm + MaxPool + Dropout
↓
⬛ Conv Block 4 — Conv2D(256) + BatchNorm + MaxPool + Dropout
↓
⬜ Global Average Pooling → Dense(512) → Dense(256)
↓
📤 Output Layer — Dense(4) + Softmax

Training: Adam optimizer, Categorical Crossentropy loss, EarlyStopping & ReduceLROnPlateau callbacks.

Data Augmentation: Rotation, flipping, zoom, shift for better generalization.

Input Size: 150×150×3 (RGB MRI images normalized to [0,1]).

📂 Dataset Information

🔴

Glioma

MRI scans of patients diagnosed with glioma tumors

🟡

Meningioma

MRI scans of patients with meningioma tumors

🟠

Pituitary

MRI scans showing pituitary gland tumors

🟢

No Tumor

Normal healthy brain MRI scans with no tumor

Recommended Dataset: Brain Tumor MRI Dataset on Kaggle (by Masoud Nickparvar) — 7,000+ images across 4 classes. Organize into dataset/glioma/, dataset/meningioma/, dataset/pituitary/, dataset/notumor/
